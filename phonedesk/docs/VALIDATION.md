# 検証結果

対象: PhoneDesk 1.0.22 / scrcpy 5.0.1 / Windows 10 x64。検証: 2026-11-03。記録更新: 2026-11-04。

- Core19件、音量6件、音声・クリップボード設定4件、アラーム方針11件、Viewer28件、Setup4件、背景5件、UHID7件とSDL入力回帰が成功。
- UHIDのBackspace通常押下・PCリピート・解放・他キーの維持・修飾キーの維持を実コードのレポート生成で検証。旧コードでは初回押下の押下/解放ペア検証が失敗した。
- 最大化した未接続ウィンドウ全体がパネルで覆われ、下端までシステム色で描画されることを確認。UIテストは専用の非表示Windowsデスクトップで実行する。
- scrcpyクライアントを変更済みソースからWindows x64へビルドし、同梱DLLでバージョン表示とSDL入力抑制を確認。
- 遠隔操作のUI・サーバー依存を除去。旧バージョンからの更新で不要な遠隔ファイルを取り除き、他のファイルを保持する試験が成功。
- A142・Android 16の専用no-learning入力欄で、SDLへWindowsキーイベントを送り、Meltypeで入力・確定した30文字が初回押下と20回のリピートで9文字になることを確認。解放後に削除が続かないことも確認。個人アプリや認証欄へ入力していない。物理キーボードを実際に長押しする手動試験とは区別する。変更前の数字入力欄ではAndroid側のリピートが動いており、ユーザー報告の元の症状を同条件で再現できたとは扱わない。
- アラーム監視はAndroid検証環境でメディア音を無視し、アラーム開始・終了を識別することを確認済み。実機の時計アプリは未確認。
- 音声切替時の映像・UHID維持、スマホ音量0でのPC音声、Windowsマスター音量同期、片方向コピー、本体の右回転・復元は過去バージョンで実機確認済み。今回のネイティブクライアントでの再確認は保留。
- 他の端末、再ログオン、保護画面は未検証。

公開ソースには個人用端末番号・SDKパス・ADB鍵・端末アプリ・検証ログ・画像を含めない。端末試験は`-Serial`を指定し、文字入力試験には別途専用fixtureが必要。
