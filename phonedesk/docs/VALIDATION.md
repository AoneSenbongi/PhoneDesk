# 検証結果

対象: PhoneDesk 1.0.17 / scrcpy 5.0.1 / Windows 10 x64 / A142・Android 16。

- Core 19件、音量情報6件、音声・クリップボード設定4件、Viewer 27件、Setup 3件、SDLインポート回帰が成功。
- 実機で音声のオン・オフ時に映像PIDとSDLウィンドウが不変であることを確認。
- スマホ音量0でPCへ音声が届くこと、Windowsマスター音量の操作・外部変更への追従を確認。
- スマホ→PCの英字、日本語・改行コピーと、PCでコピーしてもスマホのクリップボードが変わらないことを確認。
- スマホ本体の右回転・復元と、復帰ヘルパーの正常終了・ADBクライアント強制終了時の設定復元を確認。
- 保護画面の表示、他の端末、再ログオンは未検証。ネイティブscrcpyをこのソースから再ビルドする経路は未検証。

公開用コピーでは、端末番号・SDK/JDKの個人用パスを除去しています。端末試験は`-Serial`を指定してください。ViewerDeviceの文字入力試験は別途専用fixtureが必要です。試験ログ、バックアップ、端末画面、実際のクリップボード内容は含めていません。
