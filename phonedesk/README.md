# PhoneDesk

AndroidをUSBで接続すると画面を自動表示するWindowsアプリです。マウス操作と、PCに接続したキーボードでの入力に対応します。

## インストール
消灯中にUSB接続が切れると、スマホ側で画面を点灯します。「ロック」を押した場合は自動点灯を取り消し、通常のロック・スリープを維持します。

1. `dist/PhoneDesk-Setup.exe`を実行します。管理者権限は不要です。
2. AndroidをUSBで接続します。初回のUSBデバッグ許可が表示された場合は、スマホ側で許可します。
3. 接続待ちと同じウィンドウ内にスマホ画面を表示します。上部の「詳細」で左側へ端末一覧や設定を展開します。展開中だけ上部ボタンを隠し、左側の「詳細を閉じる」で元に戻します。映像サイズは維持します。

端末の縦向き・横向きの切り替えに合わせてウィンドウも追従します。「右回転」でスマホ本体を横向きにし、回転後の「戻す」（詳細では「元に戻す」）で元の回転設定へ戻せます。USB切断・アプリ終了時も元の設定へ戻します。

ミラー画面の拡大縮小・最大化ではスマホ画面の縦横比を維持します。最大化はモニター内に映像全体が収まる大きさになり、横長には引き伸ばしません。

セットアップ後はWindowsログオン時に接続待ちを開始します。ウィンドウを閉じても通知領域で動作します。終了する場合は通知領域のPhoneDeskを右クリックして「終了」を選びます。

## 音声
詳細の「PCから音を出す」スイッチを有効にすると、接続中の音をPCへ転送し、スマホ側の再生を止めます。無効にするとスマホ側から再生します。初期値は有効で、設定は次回起動にも引き継ぎます。切り替え時も画面表示とキーボード接続を維持します。スマホ本体の音量が0でもPCから再生できます。PC出力中の音量ボタン・スライダーはWindows全体の音量に同期します。Windows側で変えた音量も反映します。音声転送はAndroid 13以降に対応し、転送を拒否するアプリは対象外です。

## コピーと貼り付け
スマホで「コピー」を選んだテキストをPCへ反映します。PC側ではCtrl+Vで貼り付けられます。PCからスマホへの自動転送は行いません。日本語と改行に対応し、画像・ファイルの同期は対象外です。

## 入力
コンパネの「音量−」「音量＋」でスマホのメディア音量を1段階ずつ変更できます。

スマホ画面を直接操作する場合、キーボード入力はスマホに接続した物理キーボードとして送ります。日本語変換の対応はスマホのIMEに依存します。文字や記号の配列が合わない場合は、管理画面の「キーボード設定」で端末側の配列を変更してください。

日本語入力と変換操作は、端末に設定した物理キーボード対応IMEに依存します。Android用IMEのAPKは同梱しません。

マウスのクリックはタップ、ドラッグはスワイプ、右クリックは戻る操作です。画面表示を閉じた後は、管理画面の「画面を表示」またはUSBの抜き差しで再表示できます。

## ロック画面
「点灯」「消灯」でスマホ本体の画面を操作できます。消灯中もPC側の表示と操作を維持します。表示可能な端末ではPIN・パスワードをキーボードで入力し、パターンをマウスで操作できます。指紋・顔認証はスマホ側で行ってください。端末の制限でロック画面や保護されたアプリが黒く映る場合があります。

「ロック」は端末をロックして通常のスリープへ移行します。「消灯」はロックせず、スマホ本体の表示だけを消す操作です。ロックの解除には端末に設定した認証を使います。

起動中のPhoneDeskは`PhoneDesk.exe --screen-off`、`PhoneDesk.exe --screen-on`、`PhoneDesk.exe --lock`でも同じ操作を受け付けます。

認証情報の保存・自動入力は行いません。Androidを再起動した直後など、USBデバッグが利用できない状態ではスマホ側で最初のロック解除が必要になることがあります。

## ファイル
- インストール先: `%LOCALAPPDATA%\PhoneDesk`
- 実行ファイル: `PhoneDesk.exe`
- 画面表示エンジン: `runtime/`のscrcpy 5.0.1とADB
- 自動起動: 現在のユーザーのRunレジストリ（管理画面で無効化可能）
- エラー診断: `%LOCALAPPDATA%\PhoneDesk\last-error.txt`（画面表示失敗時のみ）

アンインストールする場合は、管理画面でログオン時の起動を無効にし、通知領域から終了して、インストールフォルダーとデスクトップ・スタートメニューのPhoneDeskショートカットを削除してください。

## 同梱ソフト
画面表示・操作には[Genymobile/scrcpy](https://github.com/Genymobile/scrcpy/releases/tag/v5.0.1)を使用しています。scrcpyはApache License 2.0です。公式配布物のLICENSE.txtとscrcpyのライセンスをruntimeに同梱しています。

同梱scrcpy.exeには、UHID入力時にWindows側のIMEを有効にしない変更を加えています。変更内容は`runtime/PHONEDESK-MODIFICATIONS.txt`に記載しています。

## 制限
Windows 10/11 x64、.NET Framework 4.x、USBデバッグとADB接続の許可が必要です。エミュレーターとWi-Fi接続は自動表示対象から除外します。PCがスリープ中・未ログオン・アプリ終了中の場合は自動表示しません。

## ビルド
`build.ps1`をPowerShellで実行します。Windows標準のC#コンパイラーを使用します。初回のみ公式scrcpy 5.0.1配布物をダウンロードし、公開SHA-256と照合します。ユーザーが操作するアプリとセットアップはexeです。

画面電源ヘルパーのソースを変更した場合は、JDKとAndroid SDKを指定して`build-power.ps1 -AndroidSdk <SDKの場所> -JavaHome <JDKの場所>`を先に実行し、同梱の`runtime-assets/phonedesk-power.jar`を更新します。
